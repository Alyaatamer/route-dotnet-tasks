# .NET & C# Learning Path Projects

This repository contains a collection of projects, exercises, and tasks covering the complete .NET backend development stack. It serves as a comprehensive portfolio and reference for learning C#, object-oriented programming, and various web frameworks within the .NET ecosystem.

## 🚀 Technologies & Topics Covered

The repository is structured into different modules based on the technology or concept:

- **C# & C# Advanced**: Fundamentals and advanced concepts of the C# programming language.
- **OOP (Object-Oriented Programming)**: Principles and applications of OOP in C#.
- **LinQ (Language Integrated Query)**: Data querying and manipulation.
- **Sql Server**: Database design and SQL queries.
- **Entity Framework Core**: ORM for data access and database migrations.
- **ASP.NET Core Web MVC**: Building web applications using the Model-View-Controller architecture.
- **ASP.NET CORE Web API's**: Designing and implementing RESTful APIs.
- **WorkShop**: Practical, hands-on workshop projects combining multiple skills.

## 📁 Repository Structure

Each folder contains specific projects and tasks related to its topic. Navigate to individual folders to see the detailed code and implementation for each section.

## ⚙️ Getting Started

1. Clone the repository to your local machine.
2. Ensure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.
3. Open the desired project folder using an IDE like Visual Studio or Visual Studio Code.
4. Restore dependencies and run the application/project.
